# 02-original-cliente

Esta pasta é somente leitura, reservada para o sistema original do cliente
(código-fonte), caso exista.

Até o momento (2026-08-17), o cliente não forneceu nenhum sistema original
em código — apenas informações de negócio, que estão registradas em
`01-documentacao/`. Por isso esta pasta está vazia.

Se um sistema original em código for recebido futuramente, ele deve ser
colocado em `02-original-cliente/sistema-original/` e nunca alterado
diretamente, conforme as regras do projeto.
